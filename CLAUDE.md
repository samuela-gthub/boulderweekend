# Writing rule

Any text a person will read goes through the humanizer pass in `.claude/skills/humanizer/SKILL.md` before it is saved or sent. That covers visible text in `boulderweekend.html` and other pages, README and docs, commit messages, pull request titles and descriptions, and issue or review comments. Use embedded mode: apply the pass and output only the final text.

The page is written in Dutch. Keep it in Dutch and apply the Dutch equivalents of the patterns.

Leave code, CSS, HTML markup, URLs, prices, dates, and addresses unchanged. Change only prose.
